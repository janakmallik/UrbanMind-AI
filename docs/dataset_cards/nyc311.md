## Purpose

Multi-class classification of urban complaints by **type**, using only
information available before the complaint is classified.

## Known Leakage Traps

The following fields were tested and **rejected** as features because they are
chosen at the same time as the target `complaint_type`:

- `descriptor` — sub-label refinement of the complaint
- `agency` — assigned during classification (HPD → HEAT, DOT → Traffic Signal)
- `location_type` — assigned during classification

Each field showed ~100% concentration against `complaint_type` in crosstabs,
indicating they encode the label rather than contextual information.

## Limitations

- Small sample (100k rows) of a much larger dataset (>30M rows)
- 6 boroughs collapsed to categorical; `UNKNOWN` used for missing
- Long-tail classes are excluded; a full multi-class model would need different handling
- Split is random, not temporal; a temporal split would be more realistic for production
